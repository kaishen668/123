# 粘粘 — 像素电子宠物 (Zhanzi the Pixel Cat)

这是一个简单的浏览器端像素电子宠物原型，作为你朋友猫咪的纪念小项目。名字叫「粘粘」，可进行喂食、喂水、玩耍、抚摸、清理、睡觉等互动。

## 特性
- 16x16 像素渲染（Canvas 缩放），无需外部图片。
- 属性：饥饿、口渴、心情、体力、清洁度，随时间变化。
- 鼠标/按键交互：喂食、喂水、玩耍、抚摸、清理、睡觉/唤醒。
- 本地存档（localStorage），刷新或关闭后可继续。
- 代码简单，易于扩展（添加音效、动画、更多事件或使用真实像素图）。

## 本地运行
1. 将 `index.html`、`style.css`、`game.js` 放在同一目录下。
2. 用浏览器打开 `index.html`（双击或拖到浏览器）。
3. 推荐 Chrome、Edge、Firefox 等现代浏览器。

## 扩展建议
- 替换 SPRITE 数组以自定义粘粘的像素外观。
- 加入多种食物、喜好系统。
- 加入“回忆”页面，可以展示你朋友和猫的照片与文字。
- 用 GitHub Pages 部署，让朋友直接访问体验。
